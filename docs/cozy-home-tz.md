# Техническое задание — Cozy Home

> Интернет-магазин товаров для дома и декора

---

## 1. Концепция

**Название:** Cozy Home  
**Слоган:** «Уют начинается с деталей»  
**Тематика:** Товары для дома и декора в скандинавском / минималистичном стиле  
**Целевая аудитория:** Люди 20–40 лет, которые обустраивают жильё и ищут небольшие декоративные вещи

## 4. Страницы и блоки

### 4.1 Главная страница `/`

**Блоки:**

1. **Header** — логотип, навигация (Главная, О магазине), иконка корзины со счётчиком
2. **Hero-баннер** — большое изображение, слоган, кнопка «Перейти к товарам»
3. **Фильтр по категориям** — горизонтальные таблетки (Все, Свечи, Текстиль, Посуда, Декор)
4. **Сетка товаров** — карточки с фото, названием, ценой, кнопкой «В корзину»
5. **Footer** — копирайт, ссылки на соцсети, контакты

**Сценарии:**

- Клик по категории → товары фильтруются без перезагрузки страницы
- Клик «В корзину» → товар добавляется, счётчик увеличивается, кнопка на секунду меняется на «✓ Добавлено», пользователь остаётся на странице
- Клик на карточку товара → переход на страницу товара
- Клик на иконку корзины → открывается виджет корзины

---

### 4.2 Страница товара `/products/:id`

**Блоки:**

1. **Хлебные крошки** — Главная → Категория → Название товара
2. **Галерея** — основное фото + миниатюры
3. **Информация** — название, цена, описание, кнопка «В корзину»
4. **Похожие товары** — 4 карточки из той же категории

**Сценарии:**

- Клик «В корзину» → товар добавляется, кнопка меняется на «✓ Добавлено», виджет корзины не открывается автоматически
- Клик на похожий товар → переход на его страницу

---

### 4.3 Виджет корзины (drawer)

Открывается как боковая панель справа при клике на иконку корзины в шапке. Не является отдельной страницей.

**Блоки:**

1. Список товаров — фото, название, цена, количество (+ / −), кнопка удалить
2. Итого — сумма заказа
3. Кнопка «Оформить заказ» → открывает модальное окно с формой

**Форма заказа (модалка):**

- Имя
- Телефон
- Комментарий (необязательно)
- Кнопка «Отправить заявку»

**Сценарии:**

- Изменение количества → сумма пересчитывается моментально
- Удаление товара → список обновляется
- Корзина пустая → заглушка «Корзина пуста» с кнопкой «Перейти к товарам»
- После отправки заявки → корзина очищается, сообщение «Заявка принята, мы свяжемся с вами»

### 4.4 Страница «О магазине» `/about`

**Блоки:**

1. Заголовок и описание магазина

## 5. Корзина и гостевые покупки

**Ключевой принцип:** регистрация не является барьером для покупки.

| Роль    | Где хранится корзина                 |
| ------- | ------------------------------------ |
| `guest` | `localStorage` браузера              |
| `user`  | В базе данных (привязана к аккаунту) |

**Сценарий — гость оформляет заказ:**

1. Гость добавляет товары → корзина хранится в `localStorage`
2. Кликает «Оформить заказ» → форма с полями Имя, Телефон, Комментарий
3. Регистрация не требуется — заявка уходит в админку и Telegram-бот
4. Корзина очищается, показывается подтверждение

**Сценарий — гость регистрируется после добавления товаров:**

1. Гость добавил товары в корзину
2. Решил зарегистрироваться / войти
3. После входа → товары из `localStorage` автоматически переносятся в корзину аккаунта
4. Если в аккаунте уже были товары → корзины объединяются

## 6. Авторизация

### Регистрация

**Сценарии:**

- Успешная регистрация → пользователь залогинен, редирект на главную
- Email уже занят → «Такой email уже зарегистрирован»
- Пароли не совпадают → «Пароли не совпадают»
- Слабый пароль → «Пароль должен содержать минимум 8 символов»

### Вход

**Сценарии:**

- Успешный вход как `user` → редирект на главную
- Успешный вход как `admin` → редирект на `/admin`
- Неверные данные → «Неверный email или пароль»
- Попытка зайти на `/admin` без авторизации → редирект на `/login`
- Попытка зайти на `/admin` с ролью `user` → редирект на главную

### Хранение сессии

- `access token` — 15 минут, хранится в памяти приложения
- `refresh token` — 30 дней, хранится в `httpOnly cookie`
- Чекбокс «Запомнить меня» продлевает сессию до 30 дней

## 7. Привязка Telegram и восстановление пароля

### Где можно привязать Telegram

1. **В личном кабинете** `/profile` — в любой момент, блок «Безопасность»
2. **На странице восстановления пароля** — если привязки нет, показывается инструкция
3. **Прямо в боте** — пользователь пишет `/start`, бот сохраняет `chat_id`

### Сценарий «забыл пароль, Telegram привязан»

1. Пользователь заходит на `/forgot-password`
2. Вводит email → система отправляет код через Telegram-бот
3. Пользователь вводит код на `/reset-password`
4. Вводит новый пароль → редирект на `/login` с сообщением «Пароль успешно изменён»

### Сценарий «забыл пароль, Telegram НЕ привязан»

1. Пользователь заходит на `/forgot-password`
2. Система проверяет — Telegram не привязан
3. Показывается инструкция:
   - Написать боту `@CozyHomeBot`
   - Отправить команду `/link ваш@email.com`
   - Вернуться и нажать «Я написал боту»
4. Бот привязывает `chat_id` к аккаунту по email
5. Система отправляет код → дальше стандартный сценарий

### Безопасность

- Код восстановления действует **15 минут**
- Команда `/link email` работает **один раз** — повторная попытка игнорируется
- Просроченный код → «Код устарел, запросите новый»
- Неверный код → «Неверный код»

## 8. Telegram-бот

### Функции бота

1. Уведомления администратору о новых заказах
2. Отправка кодов восстановления пароля пользователям

### Формат уведомления о заказе

```
🛍 Новый заказ #42

👤 Имя: Анна Коваленко
📞 Телефон: +380991234567
💬 Комментарий: Можно после 18:00

📦 Состав заказа:
— Соевая свеча «Лаванда и ваниль» × 2 — 640 грн
— Льняной плед «Туман» × 1 — 1 200 грн

💰 Итого: 1 840 грн
🕐 Время: 12:45, 29.08.2026
```

### Формат кода восстановления

```
🔐 Cozy Home — восстановление пароля

Ваш код подтверждения: 847291

⏱ Код действителен 15 минут.
Если вы не запрашивали сброс пароля — проигнорируйте это сообщение.
```

## 9. Админ-панель — детали

### Раздел «Товары»

Таблица с колонками: Фото, Название, Категория, Цена, Наличие, Действия (редактировать, удалить)

**Форма товара:**

- Название
- Описание
- Цена
- Категория (выпадающий список)
- Фото (загрузка нескольких файлов)
- Наличие (чекбокс «В наличии»)

При удалении → диалог подтверждения «Вы уверены?»

### Раздел «Заказы»

Таблица с колонками: #, Имя, Телефон, Сумма, Дата, Статус, Действия

**Статусы:**

- 🔵 Новый
- 🟡 В обработке
- 🟢 Выполнен
- 🔴 Отменён

**Фильтры:** по статусу, по дате (от — до), поиск по имени или телефону

**Детали заказа (модалка):** полные данные покупателя, состав заказа с фото, комментарий, смена статуса

### Раздел «О магазине»

Поля: заголовок, основной текст, блоки преимуществ (иконка + заголовок + текст), контактная информация

### Раздел «Пользователи»

Таблица с колонками: Имя, Email, Telegram, Роль, Дата регистрации, Действия

Действия: сменить роль, удалить пользователя
