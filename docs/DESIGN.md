# Cozy Home — дизайн-система

> Тёплый уютный минимализм: кремовый фон, шалфейно-зелёные акценты, мягкие скругления и лёгкие тени. Ближе к формулировке из ТЗ («скандинавский / минималистичный стиль»), чем предыдущая монохромная версия — заменяет её полностью.

**Тема:** light

---

## Токены — Цвета

| Название | Значение | Токен | Роль |
|---|---|---|---|
| Cream | `#F8F7F4` | `--color-cream` | Фон страницы — основной канвас |
| Beige | `#EDE8E1` | `--color-beige` | Вторичная поверхность: футер, чередующиеся секции, неактивные пилюли |
| Terracotta | `#D1C1B4` | `--color-terracotta` | Границы, теги, декоративные акценты, плейсхолдеры фото |
| Sage | `#8B9A8B` | `--color-sage` | Второстепенные акценты, бейджи, приглушённые состояния |
| Forest | `#5B6B5F` | `--color-forest` | Основной акцент — кнопки, ссылки, активные состояния |
| Ink | `#2B2B26` | `--color-ink` | Основной текст |
| Surface | `#FFFFFF` | `--color-surface` | Карточки, модалки, поля ввода — поверх Cream/Beige |

Правило: страница никогда не белая (фон — Cream), белый — только у приподнятых поверхностей (карточки, модалки).

---

## Токены — Типографика

Два семейства вместо одного — это осознанное отличие от прошлой системы:

- **Playfair Display** (serif) — заголовки. Тёплый, слегка декоративный, эмоциональный акцент.
- **Inter** (sans) — весь остальной текст и интерфейс. Нейтральный, читаемый.

### Шкала

| Роль | Семейство | Размер | Line-height | Токен |
|---|---|---|---|---|
| caption | Inter | 13px | 1.4 | `--text-caption` |
| body | Inter | 15px | 1.5 | `--text-body` |
| body-lg | Inter | 17px | 1.5 | `--text-body-lg` |
| heading-sm | Playfair Display | 24px | 1.3 | `--text-heading-sm` |
| heading | Playfair Display | 36px | 1.2 | `--text-heading` |
| display | Playfair Display | 48px | 1.15 | `--text-display` |

Вес: Inter — 400 (текст) / 500 (акценты, кнопки); Playfair Display — 600–700 (заголовки).

## Радиусы и тени

| Элемент | Радиус | Токен |
|---|---|---|
| Инпуты, теги, мелкие элементы | 8px | `--radius-sm` |
| Кнопки, карточки | 12px | `--radius-md` |
| Крупные карточки, фото | 16px | `--radius-lg` |
| Пилюли (category-фильтр), бейджи, аватар | 999px | `--radius-full` |

| Тень | Значение | Токен | Где |
|---|---|---|---|
| Small | `0 1px 2px rgba(43,43,38,.06)` | `--shadow-sm` | Кнопки, инпуты в фокусе |
| Medium | `0 4px 16px rgba(43,43,38,.08)` | `--shadow-md` | Карточки товаров, модалки, выпадающие меню |

В отличие от прошлой системы — скругления и мягкие тени используются везде, это часть идентичности, а не исключение.

## Компоненты

### Кнопка
- **Primary** — заливка Forest, белый текст, `radius-md`, `shadow-sm`. Основное действие на экране (одна-две на страницу).
- **Outline** — прозрачный/Beige фон, граница и текст Forest, `radius-md`. Второстепенные действия.

### Инпут
Поверхность Surface, граница Terracotta 1px, `radius-sm`, фокус — граница Forest. Не hairline-underline, как раньше, а полная рамка.

### Карточка товара
Surface-карточка на Cream/Beige фоне: `radius-lg`, `shadow-sm`, без hairline-разделителей — карточки существуют отдельно друг от друга с отступом (`gap`), не сеткой со швами. Фото — сверху, `radius-lg` только по верхним углам; название и цена по центру; кнопка Primary «В корзину» на всю ширину снизу.

### Фильтр категорий
Пилюли (`radius-full`): активная — заливка Forest + белый текст; неактивная — Beige фон + Ink текст, hover — Sage.

### Модалка
Surface, `radius-lg`, `shadow-md`, оверлей — Ink с прозрачностью 40%.

### Header
Cream фон, логотип (иконка домика + название шрифтом Playfair Display) слева, навигация по центру/слева, иконка корзины со счётчиком справа. Тонкая Beige-граница снизу вместо контрастного hairline.

## Do / Don't

### Do
- Скруглять всё: кнопки, карточки, инпуты, фото, бейджи — по таблице радиусов выше
- Использовать мягкие тени для разделения поверхностей вместо hairline-границ
- Serif (Playfair Display) — только для заголовков; весь остальной текст — Inter
- Держать акцент один: Forest — единственный «активный» цвет, Sage/Terracotta — фон/декор, не конкурируют за внимание

### Don't
- Не использовать чистый белый как фон страницы — только как поверхность карточек (Surface)
- Не смешивать больше одного яркого акцента на экране
- Не возвращать hairline-only разделители как основной приём — это была прошлая система

```css
  --font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;

  --text-caption: 13px;
  --text-body: 15px;
  --text-body-lg: 17px;
  --text-heading-sm: 24px;
  --text-heading: 36px;
  --text-display: 48px;

  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
  --radius-full: 999px;

  --shadow-sm: 0 1px 2px rgba(43, 43, 38, 0.06);
  --shadow-md: 0 4px 16px rgba(43, 43, 38, 0.08);
}
```
