# План выполнения работ — Cozy Home

На основе [cozy-home-tz.md](cozy-home-tz.md), [architecture.md](architecture.md) и [DESIGN.md](DESIGN.md).

## Frontend

1. Базовые UI-компоненты и токены дизайн-системы (`components/ui/`, шрифт, цвета, отступы из `globals.css`)
2. Layout: Header (навигация, счётчик корзины), Footer, корневой `layout.tsx`
3. Zustand-сторы: `cart.store` (с persist в localStorage), `ui.store`, `auth.store`
4. Главная `/`: Hero-баннер, фильтр по категориям, сетка товаров, карточка товара
5. Виджет корзины (drawer): список товаров, пересчёт суммы, удаление, пустое состояние
6. Модалка оформления заказа (форма Имя/Телефон/Комментарий)
7. Страница товара `/products/:id`: хлебные крошки, галерея, похожие товары
8. Страница «О магазине» `/about`
9. Авторизация: `/login`, `/register`, `/forgot-password`, `/reset-password`
10. Личный кабинет `/profile`: данные пользователя, привязка Telegram, история заказов
11. Админ-панель `/admin`: товары, заказы, о магазине, пользователи (защита по роли)
12. `lib/api.ts`: обёртка над fetch с авто-refresh токена, `middleware.ts` для защиты маршрутов
13. Логика переноса гостевой корзины в аккаунт после логина (`merge-cart.ts`)

## Backend и база данных

> ⚠️ Тесты для каждого модуля (14-22) пишутся **вместе с ним**, не отдельным пунктом потом — см. `CLAUDE.md`. Стек — Vitest + supertest (см. `docs/architecture.md`, раздел 8).

14. `schema.prisma`: модели User, Product, Order, OrderItem, CartItem + первая миграция
15. Auth-модуль: регистрация, логин, JWT (access/refresh), middleware проверки роли
16. Products-модуль: CRUD товаров, загрузка изображений в Cloudinary
17. Cart-модуль: серверная корзина авторизованных пользователей + эндпоинт merge
18. Orders-модуль: создание заказа (гость/юзер), статусы, фильтры и поиск для админки
    - **Обязательно: списание остатка.** Создание заказа проверяет и списывает `Product.stock` атомарно (в одной транзакции, условным `UPDATE ... WHERE stock >= N`, чтобы два параллельных заказа не ушли в минус); при обнулении — `inStock = false` (правила — `backend/src/modules/products/stock.ts`); нехватка остатка → 409 с числом доступных штук. Товары с `stock = null` не списываются.
19. About-модуль: редактируемый контент страницы «О магазине»
20. Users-модуль: список пользователей, смена роли, удаление (для админки)
21. Telegram-бот: уведомления о новых заказах, обработка `/link email`, привязка `chat_id`
22. Восстановление пароля: генерация и проверка кода (TTL 15 минут), эндпоинты reset
23. Интеграция фронта с реальным API, прогон всех сценариев из ТЗ end-to-end
24. Развёртывание: `docker-compose` на сервере, `.env`, `prisma migrate deploy`
